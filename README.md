# Неделя 03 — Скрытые пары: смесь под публичный ROC-AUC ближе к 0.95

Каждая строка — **пара скрытых наблюдений** из 512 неотрицательных признаков
(`f0000`…`f0511`). Все одномерные AUC лежат в 0.30–0.42: чем больше значение,
тем вероятнее *разные* сущности, то есть столбцы ведут себя как покомпонентные
расстояния. `target = 1` — одна скрытая сущность. Метрика — **ROC-AUC**.

Предыдущая отправка Extra Trees на стекинге с SVM дала **публичный 0.93121**.
Это совпало с 5-fold CV внутри `train.csv` (~0.93), а не с валидацией 0.946:
валидационные 560 строк легче публичного теста примерно на 0.015.

Локально лучшая смесь здесь: **CV 0.9305 / валидация 0.9485**. Публичный скор
должен вырасти за счёт train+val и остаточных признаков; скачок сразу к 0.95
маловероятен, потому что публичный тест ведёт себя как train, а не как
валидация. Загружать на Kaggle нужно новый `submission.csv`.

## Что сделано иначе

1. **Остатки после L1.** После вычитания линейного прогноза каждого столбца по
   сумме строки одномерный AUC остатков доходит до 0.66. Это измерения, которые
   *при фиксированном общем расстоянии* толкают пару в сторону «одна сущность».
   К 512 исходным столбцам добавлены агрегаты строки и групповые суммы как по
   сырому AUC, так и по AUC остатков (признаки подгоняются только на размеченных
   строках).
2. **Мешок RBF-SVM**, выбранный по CV внутри train. Деревья (LightGBM,
   Extra Trees) остаются в таблице как ориентир: на этих признаках их CV
   ниже (~0.92–0.925) и они тянули смесь вниз. В отправку входят
   `C ∈ {2,3,4}` при `γ=1.5/d` и `C=3, γ=2/d`.
3. **Итоговая подгонка на train+validation** (3080 строк вместо 2520). Правило
   базового ноутбука не смешивать выборки соблюдается для оценки: CV и таблица
   считаются на `train.csv` only. Для файла отправки размеченные строки
   используются целиком — это главный неиспользованный рычаг для публичного
   лидерборда.
4. **Один раунд self-training** на тестовых строках с `p ≤ 0.08` или `p ≥ 0.92`.

## Как запустить

```bash
python3 -m pip install -r requirements.txt
python3 train_model.py
```

Скрипт пишет `submission.csv` и `validation_results.csv`. Повторный запуск с
теми же зависимостями даёт тот же файл отправки.
